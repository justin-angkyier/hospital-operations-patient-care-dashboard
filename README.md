# Hospital Operations & Patient Care Performance Dashboard

## Project Overview

This project presents an interactive Hospital Operations and Patient Care Performance Dashboard developed using Microsoft Power BI.

The objective is to demonstrate how healthcare data can be transformed into meaningful visual insights to support the monitoring of hospital operations, patient activity and selected patient care indicators.

**Important:** This project uses entirely fictional, synthetic data. No real patient records or identifiable health information were used.

## Project Objectives

- Monitor total patient encounters.
- Analyse average patient waiting time.
- Examine simulated 30-day readmission rates.
- Monitor hospital revenue.
- Evaluate average length of stay.
- Track monthly patient volume.
- Compare patient satisfaction across departments.
- Explore inpatient admissions by admission type.

## Tools Used

- Microsoft Excel – Dataset preparation and organisation.
- Microsoft Power BI – Data modelling, measures, visualisation and dashboard development.

## Dataset Description

The synthetic dataset contains:

- 3,200 patient encounters.
- 10 fictional hospital departments.
- 20 fictional healthcare providers.
- Encounter dates covering January 2025 to October 2026.

The dataset includes encounter details, department and provider identifiers, visit types, admission types, waiting times, length of stay, treatment costs, outcomes and satisfaction scores.

## Dashboard Features

1. **Key Performance Indicators:** Total encounters, average waiting time, simulated 30-day readmission rate, total revenue and average length of stay.
2. **Monthly Patient Volume:** Trends in patient encounters over time.
3. **Patient Satisfaction:** Average satisfaction scores by department.
4. **Admission Analysis:** Distribution of inpatient admissions by admission type.
5. **Operational Summary:** Department-level performance overview.
6. **Interactive Filters:** Explore dashboard information using slicers.

## Data Limitations

All records are synthetic and created for educational and portfolio demonstration purposes.

The 30-day readmission indicators are simulated. They do not represent actual clinical outcomes and must not be used for clinical decisions, hospital performance evaluation or operational decision-making.
